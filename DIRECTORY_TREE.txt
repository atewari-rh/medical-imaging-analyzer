QUICK START COMMANDS
====================

# Navigate to project
cd /Users/atewari/Downloads/OpenshiftSustaining/medical-imaging-analyzer

# Read quick overview
cat START_HERE.md

# Setup environment
python3 -m venv venv
source venv/bin/activate
pip install -e ".[dev]"

# Run tests
pytest tests/

# See available commands
make help

# Analyze an image
mia analyze --image path/to/image.png --model chest-xray

# Batch processing
mia batch --input-dir ./images --output-dir ./results
